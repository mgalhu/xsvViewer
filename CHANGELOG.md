# Changelog

## 1.0.0

First release.

- Shows CSV, TSV and other delimited files as a table in the tab, with one shortcut to the text.
- Detects the delimiter, quotes, header row, comment lines, decimal commas, R row names and missing
  values.
- Sorting by several columns, row and column filters with number comparisons and regular expressions.
- Columns can be moved, resized, hidden and frozen; alignment and decimals can be set per column.
- Colouring by value, selection statistics, a docked panel, and export to CSV, TSV and Markdown.
- Fonts, spacing, colours and themes can be adjusted; layouts are remembered for each file.
